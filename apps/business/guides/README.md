# Проверенные иллюстрации поддержки

Добавляйте только свои проверенные инструкции без аккаунтов, токенов, ссылок подписки, IP и данных клиентов. PNG/JPEG до 2 MiB, короткие ASCII-имена. Каталог содержит объекты `id`, `title`, `file`, например `{"id":"client_step_1","title":"Первый шаг","file":"client-step-1.png"}`. По умолчанию он пуст: настоящие скриншоты приложения не выдумываются.

Файлы изображений исключены из Git, передаются оператором отдельно. Каталог монтируется только для чтения и выдаётся только вошедшим пользователям кабинета. Это не каталог входящих вложений: клиентские файлы сюда не сохраняются. Перезагружать сервер для смены каталога не требуется.
